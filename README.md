## Selected work

### [Xalt](https://benmodev.co/work/xalt)

I wanted to build an iOS app on the Windows machine I already owned. That led to a question: how much of the development loop could stay local before genuine Apple tooling was required?

Xalt grew from that question into a Windows development environment with a bounded SwiftUI-compatible local runtime and preview, shared IDE, CLI and MCP operations, and remote Xcode jobs for the Apple stages. The local preview is not Apple Simulator, and Apple build and distribution requirements still apply.

*In development. Code is private today; an open-source release is planned.*

### [Xalt Agents](https://benmodev.co/work/xalt-agents)

A convincing preview raised another question: how could I tell which behavior actually matched Apple tooling?

Xalt Agents is my calibration and evaluation research, using generated Swift tests, deterministic validation and observations from genuine Apple tools. The evidence is partial. It does not yet establish an overall compatibility score for Xalt.

*Ongoing research. Closed source.*
